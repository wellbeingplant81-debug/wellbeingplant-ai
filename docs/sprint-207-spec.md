# Sprint207 SPEC — 카드 사이에서 어긋난다

- 상태: 완료 (조사 · 구현 · 검증 통과)
- 선행: Sprint206 `efb8919`
- 기준선: regression `ran=4239 failures=0 errors=0`
- 결과: regression `ran=4253 failures=0 errors=0` · 서비스 하나와 화면
  하나 (+45/-7)

담는 관계를 값으로 확인하는 테스트 넷이 들어갔다. 말로만 "들어 있다"고
적으면 언젠가 거짓이 되고, 그때 운영자는 낱장을 다시 눌러 보게 된다.

---

## 1. 질문에 먼저 답한다

> **운영자가 지금 봐야 하는 정보가 여러 카드에 흩어져 있는가?**

**흩어져 있고, 게다가 서로 다른 순간의 것이다.**

머리줄에 누를 것이 열둘이다. 그중 기록을 읽는 여덟을 실제로 눌러 봤다.

```
Beta Snapshot          기록 읽기 1회
Beta Summary           1회
베타 분석               1회
베타 현황               1회
Release Report 복사     1회
배포 확인 정보           1회
처음 사용자 테스트        1회
패키지 확인              0회   (디스크만 본다)

여덟 개를 다 눌러 보면   기록 읽기 7회
```

### 카드 안에서는 안 어긋난다

Sprint190·192·193·199가 네 번 세운 원칙이 카드 단위로는 지켜진다 -
**카드 하나는 기록을 한 번만 읽는다.**

### 카드 사이에서 어긋난다

그런데 운영자는 카드 하나로 그림이 안 그려져 여럿을 눌러 본다.
그때마다 다시 읽는다.

```
배포 확인 정보를 누른 시각    2026-08-10T13:04:24
Beta Snapshot을 누른 시각     2026-08-10T13:04:25
같은 순간인가                 아니오
```

**한 화면 안에서 어긋나지 않게 하려고 네 번 애썼는데, 화면을 여러 번
여는 것으로 같은 어긋남이 돌아왔다.**

### 게다가 같은 것을 여러 번 담고 있다

```
Snapshot의 readiness가 Gate 안에 그대로 있는가   예
Snapshot의 flow 숫자가 Gate의 funnel과 같은가    예
Gate의 taken_at 이 Candidate와 같은가           예
```

담는 관계가 이렇다.

```
처음 사용자 테스트  (Candidate)
    배포 확인 정보  (Gate)
        Beta Snapshot
            Beta Summary + Beta Readiness
        Release Report
    + 여덟 걸음 · 지금 어디에 있는가
```

**바깥 것 하나를 누르면 안쪽 것이 전부 들어 있다.** 그런데 머리줄은
그 사실을 말하지 않는다. 그래서 운영자는 넷을 눌러 보고, 넷은 서로
다른 순간을 말한다.

## 2. 이번에 하는 것 — 새 카드를 만들지 않는다

열셋째 단추를 만들면 문제가 하나 더 늘 뿐이다. **이미 가장 바깥인
것을 먼저 보게 하고, 나머지가 그 안에 있다는 것을 말한다.**

1. 머리줄을 두 묶음으로 나눈다
   - **먼저 볼 것** — `처음 사용자 테스트` 하나
   - **낱장으로 볼 것** — 나머지
2. 그 카드 안에 무엇이 들어 있는지 한 줄 적는다
3. 복사 글에도 그 사실을 적는다

새 로직이 없다. 값도 새로 세지 않는다. **누를 것의 차례와 이름표만
바꾼다.**

### 왜 이것이 어긋남을 고치는가

운영자가 하나만 눌러도 되면 읽기가 한 번이고, 한 번이면 한 순간이다.
넷을 눌러야만 알 수 있던 것을 하나로 알 수 있게 하는 것이 곧
어긋남을 없애는 일이다.

## 4. 검증

신규 `tests/test_operator_view.py`.

### RED

1. 머리줄이 무엇을 먼저 볼지 말하지 않는다
2. Candidate 카드가 무엇을 담고 있는지 말하지 않는다

### GREEN

3. 머리줄에 묶음 이름표가 있다
4. 카드가 담은 것을 말한다
5. 복사 글에도 그 사실이 있다

### 담는 관계가 사실인지 — 화면 말고 값으로

말로만 "들어 있다"고 적으면 언젠가 거짓이 된다. 값으로 확인한다.

6. Gate의 readiness == Snapshot의 readiness
7. Gate의 funnel 숫자 == Snapshot의 flow 숫자
8. Candidate의 `taken_at` == Gate의 `taken_at`
9. Candidate 하나를 부를 때 기록 읽기 **1회**

### 건드리지 않았음

10. 새 엔드포인트 없음
11. `success_rate` · `ok` 판정 그대로
12. 두 번 불러도 데이터 폴더 그대로 · 새 사건 없음
13. 절대 경로 · 사용자명 없음
